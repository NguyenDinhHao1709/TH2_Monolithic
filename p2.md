# Bài tập PROMPT 2: E-Commerce MVP RESTful API với Express, Prisma & PostgreSQL

## 1. Yêu cầu bài toán
Hệ thống thương mại điện tử phiên bản Minimum Viable Product (MVP) với:
- Ngôn ngữ & Framework: Node.js, Express.js
- ORM: Prisma
- Cơ sở dữ liệu: PostgreSQL
- Các yêu cầu cơ bản:
  1. Cấu hình hệ thống trong file `.env`
  2. Sử dụng JWT trong bảo mật hệ thống (Authentication & Authorization)
  3. Dockerize ứng dụng với Docker Compose
  4. Thực hiện Health Check cho ứng dụng (kiểm tra API và kết nối Database)
- Thực thể dữ liệu (ERD):
  - `Role` (roleid, rolename)
  - `MemberShip` (mid, mname, score)
  - `User` (uid, username, fullname, password, roleid, mid)
  - `Order` (oid, uid, createat)
  - `Shipment` (shipid, oid, status)
  - `Product` (pid, pname, price, quantity)
  - `OrderDetail` (oid, pid, qty, unit_price)

## 3. Danh sách RESTful API Endpoints

### Hệ thống & Giám sát
- `GET /health`: Kiểm tra trạng thái hoạt động của API và kết nối PostgreSQL qua Prisma query (`SELECT 1`). Trả về `200 OK` khi database healthy.

### Xác thực & Người dùng (Authentication)
- `POST /api/auth/register`: Đăng ký tài khoản người dùng mới (mã hóa mật khẩu bằng `bcryptjs`).
- `POST /api/auth/login`: Đăng nhập hệ thống, trả về mã thông báo bảo mật **JWT token** chứa `uid`, `username`, `roleid`, `rolename`.

### Quản lý Sản phẩm (Products CRUD)
- `GET /api/products`: Lấy danh sách toàn bộ sản phẩm (Public).
- `GET /api/products/:pid`: Lấy thông tin chi tiết một sản phẩm theo ID (Public).
- `POST /api/products`: Thêm mới sản phẩm (`pname`, `price`, `quantity`) — *Yêu cầu JWT Bearer Token*.
- `PUT /api/products/:pid`: Cập nhật thông tin sản phẩm — *Yêu cầu JWT Bearer Token*.
- `DELETE /api/products/:pid`: Xóa sản phẩm — *Yêu cầu JWT Bearer Token*.

### Đơn hàng & Vận chuyển (Orders & Shipments)
- `POST /api/orders`: Đặt hàng (Thực hiện Prisma Transaction: Tạo `Order`, trừ kho `Product`, tạo chi tiết `OrderDetail`, tự động khởi tạo `Shipment` với trạng thái ban đầu `Pending`) — *Yêu cầu JWT Bearer Token*.
- `GET /api/orders`: Xem danh sách đơn hàng kèm chi tiết sản phẩm và trạng thái vận chuyển — *Yêu cầu JWT Bearer Token*.

### STT 3: Giải thích mã nguồn Prisma ORM (1 điểm)

### STT 6: POSTMAN: Đăng ký tài khoản mới -> tự động thiết lập role là `normal` với `score` là `10` -> Đăng nhập -> Hiển thị token (1 điểm)
- **Bước 6.1 — Đăng ký tài khoản mới trên Postman:**
  - **Method:** `POST`

      "username": "khachhang1",

      "password": "123"
    }

  - **Kết quả trả về (`201 Created`):** Tự động thiết lập `"role": "normal"` và `"score": 10`:
    ```json
    {
      "message": "User registered successfully",
      "user": {
        "uid": 2,
        "username": "khachhang1",
        "fullname": "Nguyen Van A",
        "roleid": 2,
        "role": "normal",
        "mid": 1,
        "membership": "Normal",
        "score": 10
      }
    }
    ```
- **Bước 6.2 — Đăng nhập tài khoản vừa tạo trên Postman:**
  - **Method:** `POST`
  - **URL:** `http://localhost:5000/api/auth/login`
  - **Body (raw -> JSON):**
    ```json
    {
      "username": "khachhang1",
      "password": "123"
    }
    ```
  - **Kết quả trả về (`200 OK`):** Hiển thị chuỗi **JWT `token`** — copy chuỗi `token` này để dùng cho STT 7.

### STT 7: POSTMAN: Thực hiện luồng đặt hàng (1 điểm)
- **Bước 7.1 — Đặt hàng KHÔNG dùng token -> Báo lỗi:**
  - **Method:** `POST`
  - **URL:** `http://localhost:5000/api/orders`
  - **Tab Authorization:** Chọn **No Auth** (không truyền token).
  - **Body (raw -> JSON):**
    ```json
    {
      "items": [
        { "pid": 1, "qty": 2 },
        { "pid": 2, "qty": 5 }
      ]
    }
    ```
  - **Kết quả:** Báo lỗi **`401 Unauthorized`** (`{"message": "Access denied: No token provided"}`).

- **Bước 7.2 — Sử dụng token -> Đặt hàng gồm sản phẩm X mua 2, sản phẩm Y mua 5:**
  - **Method:** `POST`
  - **URL:** `http://localhost:5000/api/orders`
  - **Tab Authorization:** Chọn **Bearer Token** -> Dán `token` vừa lấy ở STT 6 vào.
  - **Body (raw -> JSON):**
    ```json
    {
      "items": [
        { "pid": 1, "qty": 2 },
        { "pid": 2, "qty": 5 }
      ]
    }
    ```
  - **Kết quả (`201 Created`):** Đơn hàng được tạo với `createat` là thời gian hiện hành, kèm `orderDetails` (X mua 2, Y mua 5) và tự động tạo `shipments` (`status: "Pending"`).

- **Bước 7.3 — Xem thông tin đơn hàng & detail:**
  - **Method:** `GET`
  - **URL:** `http://localhost:5000/api/orders` (hoặc `http://localhost:5000/api/orders/1`)
  - **Authorization:** **Bearer Token**

- **Bước 7.4 — Chuyển sang Shipment & Hiển thị thông tin Shipment:**
  - **Method:** `POST` (để chuyển trạng thái sang `Shipping`) hoặc `GET`
  - **URL:** `http://localhost:5000/api/shipments`
  - **Authorization:** **Bearer Token**
  - **Body (raw -> JSON):**
    ```json
    {
      "oid": 1,
      "status": "Shipping"
    }
    ```
  - Hoặc xem danh sách Shipment tại: `GET http://localhost:5000/api/shipments`
